# email-file-recovery
A tool to recover files via email attachments using Streamlit.
# 📧 Email File Recovery Tool

This is a Streamlit-based application designed to help users recover permanently deleted files from their mobile devices by searching for old attachments in their email accounts.

## 🚀 Features
- Search emails by date range.
- Filter by keywords.
- Direct download of attachments from the web interface.

## 🛠️ Setup
1. Clone this repository.
2. Install requirements: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`

## ⚠️ Important
To use this app with Gmail, you must generate an **App Password** from your Google Account settings.
